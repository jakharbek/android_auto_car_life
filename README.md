# Monza Auto

Android Auto на штатной магнитоле Chevrolet Monza, которая умеет только CarLife.
Телефон подключается к магнитоле кабелем и показывает на ней Android Auto: карты, музыку, голосовой помощник.

## Как это работает

```
Android Auto (на телефоне) ⇄ Monza Auto ⇄ USB-кабель (CarLife) ⇄ магнитола
```

- Для Android Auto приложение — головное устройство: подключается к его «серверу головного устройства»
  (127.0.0.1:5277), получает картинку 1280×720, отдаёт касания и микрофон.
- Для магнитолы приложение — телефон с CarLife: принимает касания и кнопки руля, отдаёт видео H.264 и звук.
- Видео перекодируется на телефоне: декодер Android Auto рисует прямо во входную поверхность кодировщика,
  кодировщик повторяет кадр каждые 100 мс и делает ключевой кадр каждую секунду — магнитола не теряет картинку
  на неподвижном экране.

Стандартные средства Android, без сторонних библиотек.

## Установка

1. Скачайте `monza-auto-<версия>.apk` из Releases и установите.
2. Откройте приложение, разрешите микрофон и уведомления.
3. Загрузите сертификат головного устройства (см. ниже), если его нет в сборке.
4. Android Auto → Настройки → 10 раз нажмите «Версия» → меню ⋮ → «Вкл. сервер головного устр-ва» (в английской версии «Start head unit server»).
   Сервер одноразовый: после обрыва его нужно включить снова и нажать в приложении «Подключить Android Auto снова».
5. Подключите телефон к USB машины, включите CarLife на магнитоле и разрешите приложению доступ к USB.

При первом запуске открывается **мастер настройки** (его можно открыть снова кнопкой на главном экране).
Он проходит по шагам: Android Auto → разрешения → работа в фоне → сертификат → сервер головного устройства →
подключение к машине → итог. На каждом шаге — объяснение, проверка прямо на телефоне и кнопка, которая исправляет
проблему (даёт разрешение, снимает ограничение батареи, открывает нужные настройки).

Кнопка **«Диагностика»** проверяет всё сразу и показывает список: что нужно исправить (красное), что желательно
(жёлтое), что в порядке. У каждой проблемы — что сделать и кнопка исправления. Отчёт можно отправить текстом.
Проверяется: Android Auto, сертификат (наличие, ключ, сроки), сервер головного устройства (без подключения к нему:
он одноразовый), микрофон, уведомления, ограничения батареи, аппаратный кодировщик видео, USB и разрешение на него,
связь с магнитолой (протокол, модель, экран, авторизация), связь с Android Auto (отказ, зависший сервер, отказ
сертификата), режим звука, приложение по умолчанию для магнитолы (находит другие приложения, которые тоже
открываются при подключении CarLife по USB, и ведёт в их настройки «Открывать по умолчанию», чтобы сбросить).

Настройки в приложении:

- **Звук**: «Авто» — как просит магнитола; «Через USB» — звук Android Auto идёт в магнитолу по кабелю;
  «С телефона» — звук играет телефон (через Bluetooth машины).
- **DPI** — масштаб интерфейса Android Auto. **Битрейт** — качество видео.
- **Журнал** — кнопка «Поделиться журналом», если что-то не работает.

## Если при подключении открывается другое приложение

Android запоминает, какое приложение открывать при подключении магнитолы. Если раньше было выбрано другое
(«Всегда»), Monza Auto не получит подключение. Что сделать: Настройки телефона → Приложения → то приложение →
«Открывать по умолчанию» → «Сбросить настройки по умолчанию». Затем переподключите кабель и в окне выбора
отметьте Monza Auto и «Всегда». Диагностика сама находит такие приложения и даёт кнопку на нужную страницу.

## Сертификат головного устройства

Android Auto принимает только головные устройства с сертификатом, которому он доверяет. Сертификат в репозиторий
не кладётся. Два способа добавить:

- в приложении: «Загрузить сертификат и ключ (.pem)», выбрать сразу оба файла (сертификат и закрытый ключ, PEM);
- в сборку: секреты репозитория `HU_CERT_PEM` (текст сертификата) и `HU_KEY_PEM` (текст ключа),
  Settings → Secrets and variables → Actions. CI положит их в APK.

## Сборка

JDK 17, Android SDK.

```bash
./gradlew testDebugUnitTest assembleDebug
```

CI (`.github/workflows/build.yml`) на каждый push запускает тесты и собирает release APK; с основной ветки
публикует его в Releases.

Постоянный ключ подписи (чтобы новые версии ставились поверх старых) — секреты `MONZA_KEYSTORE_BASE64`
(keystore в base64), `MONZA_KEYSTORE_PASSWORD`, `MONZA_KEY_ALIAS`. Без них каждая сборка подписывается новым
временным ключом.

```bash
keytool -genkeypair -keystore monza.jks -alias monzaauto -keyalg RSA -keysize 2048 -validity 10000
```

```bash
base64 -w0 monza.jks
```

## Структура

| Где | Что |
|---|---|
| `carlife/` | протокол магнитолы: кадры USB (`Frames`), сообщения (`Msg`, `Bodies`), сеанс (`CarLifeLink`), касания (`TouchMapper`) |
| `aa/` | протокол Android Auto: соединение и TLS (`AapLink`), сообщения и описание устройства (`AaProto`), сертификат (`HuCredentials`) |
| `media/` | перекодирование видео (`Transcoder`), H.264 (`H264`), микрофон телефона (`PhoneMic`) |
| `proto/` | кодирование protobuf (`Pb`) |
| `LinkService` | связывает всё вместе, держит соединения |
| `setup/` | проверки для мастера и диагностики: правила (`Rules`) и сбор фактов на телефоне (`Probes`) |
| `ui/` | мастер настройки (`WizardActivity`), диагностика (`DiagnosticsActivity`), общие элементы (`Ui`, `BaseActivity`) |
| `Diag` | что последний раз видели соединения (для диагностики) |
| `MainActivity` | главный экран: состояние, управление, настройки, журнал |

## Ограничения

- Звонки — через Bluetooth телефона, как обычно.
- Если магнитола требует авторизацию в форме, отличной от «2.0;…», соединение не установится (будет видно в журнале).
- Микрофон — телефона, не машины.
- Не отвлекайтесь за рулём.
